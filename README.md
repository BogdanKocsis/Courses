# O'Reilly Java Projects

This repository contains projects and code examples developed as part of structured online courses focused on Java and backend development.  
The goal of this repository is to consolidate practical knowledge gained through guided learning and to serve as a reference for core backend concepts.

---

## Courses Included

### Complete Java Developer Course
A comprehensive course covering the fundamentals and advanced aspects of Java programming.

**Key topics:**
- Core Java syntax and concepts
- Object-Oriented Programming (OOP)
- Collections and Generics
- Exception handling
- Multithreading basics
- Best practices in Java development


---

### Zero to Hero: Java Spring Boot and JPA Mastery
A hands-on course focused on building backend applications using Spring Boot and JPA.

**Key topics:**
- Spring Core and Dependency Injection
- Spring Boot fundamentals
- JPA and Hibernate
- RESTful APIs
- Database integration
- Layered application architecture
